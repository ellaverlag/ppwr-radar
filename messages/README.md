# Sprachdateien (i18n-Fundament)

- `de.json` – Standardsprache, einzige gepflegte Quelle (Phase 1).
- `en.json` – Gerüst für den späteren EN-Ausbau („PPWR Radar EU", Phase 2):
  identische Keys, Werte sind vorerst die deutschen Fallbacks. Übersetzen,
  nicht umbauen.

Wissensbasis-Inhalte (Anforderungen, Auslegungen, Rollen-Definitionen,
Wizard-Fragen) kommen ausschließlich aus der Datenbank und laufen nicht
über diese Dateien.
